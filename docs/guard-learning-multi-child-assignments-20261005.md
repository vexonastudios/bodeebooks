Each existing list card also offers Assign to more children with a Lucide Users icon. That editor reuses the source words, teaching hints or exact definitions/context, excludes the original child, and begins with no additional children selected. An active assignment replaces each selected child's current list; earlier results remain in Archives. Each child gets a separate list and word/term identities, keeping study history and progress independent. Editing an assigned list continues to edit only that child's list.
