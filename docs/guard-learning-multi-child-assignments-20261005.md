# Parent multi-child learning assignments

Parents can select one or more children in either New List editor, with checkbox chips, Select all, Clear, a selected count and an explicit Assign to N children action. Each existing list card also offers Assign to more children with a Lucide Users icon. That editor reuses the source words, teaching hints or exact definitions/context, excludes the original child, and begins with no additional children selected. An active assignment replaces each selected child's current list; earlier results remain in Archives. Each child gets a separate list and word/term identities, keeping study history and progress independent. Editing an assigned list continues to edit only that child's list.

The shared parent-only assignment queue freezes the reviewed content and per-child request/list UUIDs. Confirmed children are skipped on retry; a lost or mismatched reply retains the exact remaining request. Controls prevent double submission and changes while confirmation is pending, with named partial-save notices and an in-editor retry. Keep the editor open while retrying; this queue is not persisted across closing the page. All child names are text nodes.
