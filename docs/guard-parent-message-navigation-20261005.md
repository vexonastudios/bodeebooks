# Parent website Messages navigation

On mobile, Messages opens with Children selected. Children and Groups have separate accessible tabs and remembered searches, so family/sibling groups no longer push individual children down the screen. Selecting a group or opening a child from a notification chooses its matching tab; the conversation back button returns to that list and restores row focus across a background list refresh. Existing unread counts and newest-child-first ordering remain intact.

The Groups tab contains a compact New group message action, Family conversation, and one scrolling group list. Rows show Lucide icons, ellipsized member names, participant counts, chat type and an explicit Closed badge. Full participant names remain available through the accessible label and title. Groups containing every active child show All children. Parents retain the existing selected-recipient composer, group history and close/reopen controls.

A 44-pixel settings button opens a centered native dialog. Kid-to-kid chats uses a switch inside a full clickable label, a short explanation and an in-dialog save status. It still uses the existing peer-message-settings API and changes only on an explicit parent toggle. A failed save restores the last confirmed state; stale in-flight group reads cannot replace a newly confirmed toggle. Escape and Close return focus to settings. About messages is available inside this panel rather than consuming the main list.

The maintained cloud Messages module is selectively exported with its website import paths rewritten. Only the new parent-scoped CSS block was added to the website, preserving its newer desktop sizing/resizing styles. Messages import, stylesheet and outer workspace cache keys and generated asset hashes were updated. Earlier multi-child learning assignment, Assistant formatting and Parent Account changes are preserved. No API, database, dependency, Windows installer or update-feed change is required; Windows remains 1.2.287.
